# CS370-Portfolio

My pirate intelligent agent project

For this projectI worked on a pirate agent that had to learn how to find treasure in a maze. Some of the code was already provided, including the maze setup and other files needed for the project. My job was to work on the training code and use deep Q-learning to help the pirate learn from its moves. I had some problems getting everything to work correctly, so I had to go back and make changes several times. Even though my final test still showed false, I was able to run my code and understand more about how the training process works.

What do computer scientists do and why does it matter?

Computer scientists create programs and use technology to solve different problems. They also test software, fix errors and find ways to improve how things work. Their work is important because so many people and businesses depend on technology every day. This course showed me how computers can learn from information and make decisions instead of always following the same instructions.

How do I approach a problem as a computer scientist?

When I have a problem with my code, I try to figure out what went wrong and what I need to change. I usually go back through my work, check for mistakes and try again. With this project, I had to do that a lot because my code was not always giving me the results I needed. I learned that I have to be patient and take my time instead of expecting everything to work on the first try.

What are my ethical responsibilities to Users and organizations?

I believe my responsibility as a computer scientist is to make sure the programs I create are safe and work the way they should. I also need to respect people's privacy and protect their personal information. Companies depend on technology to handle important tasks, so it is important to create programs that are fair and reliable. I also think being honest about mistakes and fixing problems is part of doing my job the right way.
